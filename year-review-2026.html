NBA switchover

Completed 21 Jul

NBA moved off the shared database onto its own API servers and its own MongoDB cluster. The data moved by dump and restore, after a replica-set approach was tested and ruled out.

Played a role

Redis switchover on dev

Port 6380 → 6379, Redis 8.4.4

Moved dev Redis in place onto the new 8.4.4 build, cutting over from port 6380 to 6379, and added the playbook that moves it onto the standard install path afterwards.

Automation

Ansible playbooks for Redis and MongoDB

dev, staging and production

Fresh-install and rolling-upgrade playbooks for Redis 8.4.4 and MongoDB 8.0.17. Added the teardown, Sentinel-rename and finalize-path playbooks, and an isolated copy for the f1-dummy cluster so it can never point at production.

Fixing and planning

Wiz vulnerability fixes

November · nginx ticket due 18 Dec

nginx is built from source on every app fleet and carried two HTTP/2 flaws. Audited every build, set one standard build and a 12-step per-fleet plan, and upgraded dev NBA and three staging fleets to 1.30.8. Dev and staging also have the kernel and libbrotli fixes; production is next.

DFE and DFANX

From 17 Nov · prod push 24 Nov

Two more mobile-app projects that share a Bitrise workspace. Worked on the Bitrise security incident, fixed a failing dev deploy, and pushed DFE and DFANX to production on 24 November.
